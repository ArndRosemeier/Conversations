# solarpolis-dialogue v0.1.0

Incremental, seeded group conversations for game speech bubbles. Hosts can create residents from profiles, request one turn at a time, and pause or stop immediately when a party moves on.

- Groups of 2–6, balanced seeded turn selection, multiple factual topics, pursuit follow-ups and subjective opinions.
- English voices from temperament, pursuits, body kind, age group and home. No per-resident scripts required.
- Bubble `pieces` bounded to 90 Unicode code points; short source explanations preserve evidence ownership and uncertainty.
- One shared population/canon catalog; small party belief/context sessions; runtime entities, profiles and recipient-scoped facts.
- `seed` plus `day`/`occasion`, pause/resume, paired session/conversation checkpoints. No wall clock or global RNG.
- Worker-safe ESM with TypeScript declarations and no runtime dependencies. English is an explicit module; the core imports no concrete language.
- Separate extensible Solarpolis canon module: 180 attributed world-bible assertions, excluding the Arrival Commons sample cast/events.
- Legacy two-person simulator and setting-session APIs remain available. Opt into `mode:'ambient'` or the incremental API.

## Download

Install `solarpolis-dialogue-0.1.0.tgz` with npm or another local-archive package manager. This release is not an npm registry publication.

The roughly 0.5 MB `english-lexical-pack.mjs` is optional and absent from the SDK archive. Load it explicitly as `languageOptions.lexicalPack`. Keep `language-source-manifest.json` and `lexical-NOTICES.txt` with it. `SHA256SUMS.txt` covers all four distribution assets.

## Verification and limits

105 automated tests pass, including deterministic replay, pause/save/restore at every turn boundary, group participation, private/delayed knowledge, profile voices, multiple topics, an alternate language adapter, 1,000 registered profiles with 20 live small sessions, and worker execution. The actual archive was installed in a separate consumer project: all package exports, TypeScript declarations and optional lexical loading passed. Both existing browser bundles build; the Willowbrook integration demo passes.

This remains a bounded procedural conversationalist. Longer sessions can reveal repeated patterns. Hosts manage spatial parties, timing, persistent resident knowledge when moving between sessions, and world-save identity. The thousand-resident check verifies allocation structure, not a game's frame budget. Selected canon is not the complete world bible. Long host-authored sentences may wrap across several bubble pieces without losing their meaning.
